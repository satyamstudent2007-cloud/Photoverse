## 🐛 Troubleshooting

### Dependency installation fails

Try upgrading pip:

```bash
python -m pip install --upgrade pip
```

Then reinstall:

```bash
pip install -r requirements.txt
```

### Python version error

Check your Python version:

```bash
python --version
```

Use the Python version specified by the project.

### GPU/CUDA problems

Check your GPU environment and verify that the installed ML libraries are compatible with your CUDA/PyTorch version.
